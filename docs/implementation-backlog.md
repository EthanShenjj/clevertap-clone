# CleverTap Clone 实施任务清单

本表保留最初的 P0 拆解，供后续扩展对照；不作为当前完成记录。2026-11-19 已交付 Next.js 前后端、SQLite、六类业务资源 API 和核心交互闭环，实际范围、替代方案及验证结果见 [实际架构](architecture.md) 与 [验证记录](verification.md)。嵌套条件、生产消息发送等条目仍未实现。

## P1 候选任务池

以下按演示价值选择，不计入 P0 承诺：

| 优先方向 | 候选任务                                                        | 复用基础                           |
| -------- | --------------------------------------------------------------- | ---------------------------------- |
| 分析深度 | Cohorts、Flows、Pivots                                          | 查询字典、图表、看板与人群下钻     |
| 渠道广度 | SMS、WhatsApp、RCS、Web Push、App Inbox                         | 活动流程、模板、内容接口和模拟日志 |
| 个性化   | 商品目录、推荐预览、Reminders                                   | Schema、个性化预览和时间模拟       |
| 预测分群 | 目标、预置评分分布和人群展示                                    | 分群、可达性和结果图表             |
| 实验优化 | 独立实验、Product Experiences、IntelliNODE、Lifecycle Optimizer | 稳定分流、Journey 和结果比较       |
| AI 演示  | Analytics Agent、Segment Builder Agent、Scribe                  | 结构化条件、分析配置、渠道内容模型 |
| 数据接入 | CSV 本地导入、连接器目录                                        | 数据校验、用户和事件模型           |

真实后端与供应商接入需要单独的规格、执行保障和验收，不以“替换几个 Mock 接口”估算。
